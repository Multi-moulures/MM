# multimoulures.com

Site Astro bilingue (FR à la racine, EN sous /en/).

- Faits de l'entreprise : src/data/site.ts (un seul endroit à modifier)
- Couleurs et polices : src/styles/global.css (tirées des fiches techniques 2026)
- Pages : src/components (une composante par type de page, FR et EN ensemble)
- Les zones surlignées en jaune (classe .todo) sont à compléter avant la mise en ligne.

Commandes : npm install, npm run dev (aperçu local), npm run build (génère dist/ pour Cloudflare Pages).
